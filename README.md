# Firmas de mail de Geben

Íconos que usan las firmas de Gmail del equipo de [Geben Argentina](https://www.gebenargentina.com).
Están acá porque Gmail solo muestra imágenes publicadas en internet.

No borrar ni renombrar los archivos: las firmas ya enviadas los siguen pidiendo.

- Redes: [Simple Icons](https://simpleicons.org) (CC0).
- Pin: [Lucide](https://lucide.dev) (ISC).
